# Palha Weddings — Landing Page

Site estático, responsivo e pronto para publicar no GitHub Pages ou na Vercel.

## Arquivos
- `index.html`: landing page completa (CSS, JavaScript e logos incorporados).
- `vercel.json`: configurações básicas da Vercel.
- `.nojekyll`: evita processamento desnecessário pelo GitHub Pages.

## GitHub
1. Descompacte este ZIP.
2. Crie um repositório no GitHub e envie os arquivos diretamente à raiz (sem pasta intermediária).
3. Para GitHub Pages, em Settings > Pages, use Deploy from a branch e a pasta `/ (root)` da branch principal.

## Vercel
1. Importe o repositório do GitHub em Vercel > Add New > Project.
2. Detecte como projeto estático / Other (sem build command).
3. Publique com Deploy.

Não há dependências a instalar.
